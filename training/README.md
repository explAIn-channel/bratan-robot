# training — нейросеть езды по лидару

Комплект для проверки и переобучения политики движения `brain/assets/navigation/actor.onnx`.
Работает на обычном ПК, без телефона и платы.

```bash
cd training
pip install -r requirements.txt
python verify.py
# PASS: model/checkpoint identity, contract, 128 ONNX/PyTorch vectors, six simulator scenarios, gradients, final-report scenario selection.
```

## Модель

| | |
|---|---|
| Архитектура | MLP 228 → 128 → 128 → 64 → 2, Tanh |
| Вход `features` | float32 `[batch, 228]` |
| Выход `twist` | `[batch, 2]`: линейная 0…0,25 м/с, угловая −0,25…+0,25 рад/с |
| Инференс | среднее прямого и зеркального прохода: `0.5*(actor(x) + mirror(actor(mirror(x))))` — уже внутри ONNX |
| Нормализация | `feature_mean`, `feature_std` вшиты в веса |

Вектор признаков (`contract.json`):

| Смещение | Размер | Что |
|---:|---:|---|
| 0 | 72 | лидар сейчас: 360 лучей → 72 сектора, логарифм дальности |
| 72 | 72 | лидар 0,3 с назад |
| 144 | 72 | лидар 2,0 с назад |
| 216 | 10 | 5 точек локального пути `(x, y)` в системе корпуса, шаг по длине дуги, просмотр 1 м, масштаб 2 м |
| 226 | 2 | измеренные линейная и угловая скорости |

Геометрия в контракте: корпус 409×286 мм (`footprint_m`), выпуклый многоугольник защиты из 8 точек, радиус колеса 33,3 мм, 942,4 тика энкодера на оборот, поворот лидара 1,5062 рад.
Лидар: 360 лучей на оборот, физическое окно 0,2–8 м.

## Обучение

Запуск `ppo-static-home-20260906`, CPU, с нуля, seed 260906.

1. **Подражание учителю.** Четыре раунда по 24 000 примеров геометрического учителя (`pure_pursuit.py`), итоговая imitation loss 0,0102. Код — `bootstrap_actor` в `train_rl.py`, генератор — `simulate_expert_dataset.py`.
2. **PPO.** 800 обновлений, 12 параллельных сред, горизонт 128, всего 1 228 800 шагов среды.
   gamma 0,99, GAE λ 0,95, clip 0,2, 4 эпохи, minibatch 256, коэффициент энтропии 0,003, ограничение нормы градиента 0,5, lr 3·10⁻⁴ с линейным спадом до 5 %.

Симулятор (`source/sandbox/rosnav_shadow_v1/`) крутит робота на карте 5 см/пиксель: старт и цель, лучи лидара, локальный путь, препятствия. Модель училась на карте квартиры автора; её в репозитории нет, вместо неё синтетическая квартира 10 × 7 м из `make_map.py` — на ней работают `verify.py` и новое обучение.
Шаг управления 0,1 с, отклик угловой скорости 0,55 с. Награда: продвижение к цели, время, рывки скорости, близость и приближение к препятствиям, столкновение, достижение цели — формулы в `DriveEnv.step` (`rl_env.py`).
Сценарии: `clear`, `static` (неподвижные препятствия), `standing` (стоящий человек); есть также `walking`, `sudden`, `crowded`.

## Результат

Лучшей оказалась модель после первого обновления PPO (1 536 шагов после подражания), а не после восьмисотого. Оценка по 120 эпизодов на сценарий:

| Сценарий | Доехал | Столкнулся | Не успел |
|---|---:|---:|---:|
| clear | 120 | 0 | 0 |
| static | 116 | 1 | 3 |
| standing | 119 | 1 | 0 |

К 800-му обновлению успешность упала до 87,5–88,3 %, столкновения выросли до 10,8–12,5 %: дальнейший PPO качество не улучшил.

На живом роботе колёсами сейчас управляет не нейросеть, а pure pursuit по маршруту планировщика (`brain/bratan/body/skills.py`).
Модель загружается и получает сканы (`brain/bratan/body/policy.py`), но команд не выдаёт: качество езды по одной оценке в симуляторе не доказано.
